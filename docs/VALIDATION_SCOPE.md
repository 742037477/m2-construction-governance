## 治理效果成立的环境条件

1. 宣称受治理的操作实际走登记入口；绕过该入口的宿主原生工具不在程序强制范围内。
2. 信任配置、公钥 pin、源码和状态库受到部署环境的写权限保护；本地完整性校验不能抵御有能力整体改写可信组件的宿主。
3. 授权、候选、角色证明和回执真实且当前有效；作者、审者和父级接受的实际身份映射由宿主负责。
4. 测试与审查覆盖实际需求，不能只检查形式齐备。工具进程的系统能力由宿主限制，固定 argv 不是 OS 沙箱。

这些条件应在复现报告中明确，而不是隐藏在“框架保证安全”的总括表述中。任何新的反例应保留原现场、当前范围和观察结果；无法确认的原因标为未知。
