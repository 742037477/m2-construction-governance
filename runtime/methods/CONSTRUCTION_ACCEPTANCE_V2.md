# 施工治理研究验收参考（公开派生 2.0-research.1）

本文由固定历史方法整理，删除项目内部排期和其他产品安排，用于定义可复现的研究问题。它不提供当前任务授权，也不表示检查已经通过。

## 三个评价维度

1. **治理施工**：当前范围授权、逐次效果 Gate、意图/回执、真实 TEST/BUILD、固定候选、非作者审查、局部只读裁决、单次内部回交、父集成、CEO 接受、PRE、单次发布及 POST 是否绑定同一实际对象。保留 CK01–CK13 的断言，不降低执行门。
2. **长任务连续性**：多阶段交接和恢复前后，任务、规则、候选、授权、租约、attempt、待审和 UNKNOWN 是否对应当前原件；摘要和记忆中的事实是否有证据。结论限实际观察的任务及检查点，不承诺任意长任务不出错。
3. **失败经验复用**：保留原失败、已证原因、假设/未知、证据及适用条件；相关逻辑未变可继续参考；相关变化只复核受影响条目。历史经验与当前 advisory 分开，不带入旧权限、不重放 UNKNOWN。

## 结果如何报告

逐项使用 NOT_RUN、PASS、FAIL 或 INDETERMINATE，并记录基线、候选、输入、相关配置、实际结果、原始证据、覆盖及限制。只读错误提示不能单独证明没有产生效果；应核对实际目标、调用次数或消费记录。

已有证据仅在相关字节、依赖、配置和验证范围一致，且原件复核后可复用。更改对象须形成新候选。原失败不因后续修复被改写，UNKNOWN 不由摘要补成成功。来源完整性和当前授权预算、有效期仍应核验。

本研究参考不设置 token 节省、检索速度或对照实验胜出的目标。项目参与者若开展额外研究，应另行记录研究问题、方法与限制，不借此改写历史结果。
